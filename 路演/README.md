# 路演材料

这里只放比赛和路演用的东西，不参与员工端、配置端的构建和发布。产品文档在仓库根目录的 `docs/`。

| 目录 | 内容 |
| --- | --- |
| `项目介绍.md` | **路演口径唯一文档**：决赛 PPT 终版 19 页转写的项目叙事，AI 与评审先看这个 |
| `PPT/` | 路演幻灯片脚本、成品和预览。在该目录里用 `./build.sh deck脚本/某脚本.js` 生成 |
| `视频/` | 录制和合成路演视频的脚本。在仓库根目录运行，例如 `node 路演/视频/record-green.mjs` |
| `视频成品/` | 已经导出的 MP4 |
| `文档/` | 赛题、路演需求、剧本和方案文字 |
| `原型/` | 可点击的交互原型，数据是写死的。发布用仓库根目录的 `bash scripts/deploy-prototype.sh`，站点是 `mindbridge-demo.pages.dev` |

内测产品地址是 `https://mindbridge-beta.pages.dev/`，不要把路演原型或旧的 `mindbridge-app-8j6` 地址写进新的对外说明。
