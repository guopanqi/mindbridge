## 三、Demo 嵌入方案

### 3.1 三段视频的分镜

所有录屏用同一个演示账号、同一个代号（如「晚风-QBUX」），故事连续。

**视频 A · 日常线（60–75s，配字幕，无口播音轨）**

1. 钉钉工作台图标 → 启动页「正在建立匿名连接」三步（3s）
2. 树洞欢迎语；输入「今天和一个客户扯皮，一直说过两天过两天，烦死了」（8s）
3. AI 回应 + 出现活动卡「三分钟呼吸着陆法」（6s）
4. 点开 → 前测滑块 → 呼吸圆跟练**加速剪辑到 10s** → 后测 → 「已完成」（20s）
5. 回到对话「好多了 谢谢你」；字幕：三天后（2s 黑场淡入）
6. 回访卡「上次做完呼吸练习后，今天有没有感觉稍微松一点？」→ 点选（8s）
7. 「我的活动」页看到这次记录与前后差值（6s）

**视频 B · 危机线（75–90s）**

1. 接着上一段对话，输入「好累，好想死」（5s）
2. AI 关切回应 + 「你现在安全吗」；下方出现热线卡（8s）
3. 「专业支持预约」同意卡：说明疗愈师只看到个案编号与风险级 → 点「我想预约」→ 「已提交 · 个案编号 xxxx」（12s）
4. 切场：疗愈师工作台（桌面），个案列表只有编号、风险级、时间，没有任何身份 → 接单 → 记录跟进（25s）
5. 切回手机：卡片变为「疗愈师已接单」；「我的」页可撤回授权（10s）
6. 字幕收尾：「AI 吹哨，人来接住。全程没有人知道他是谁。」（4s）

**视频 C · HR 线（40s）** 或用 3 张全屏截图代替

1. 组织情绪节律曲线（含钉钉办公节奏叠加）
2. 部门分布：某部门显示「样本不足 10 人，不展示」
3. 干预效果：活动完成率与前后自评均值
4. 行业对照（标「模拟数据」角标——这是诚实，也是评委问答的防线）

### 3.2 录制规格

| 项 | 规格 | 理由 |
| --- | --- | --- |
| 手机端画幅 | 竖屏 **1170×2532** 或用桌面 Chrome 设备模拟 390×844 ×3 倍录制，导出 1080×2340 | 现场投影是 16:9，竖屏视频放在页面右侧 1/3，左侧留字幕和讲解点 |
| 桌面端画幅 | 1920×1080 | 疗愈师台与 HR 看板 |
| 编码 | MP4 / H.264 High / AAC 48k / ≤ 8 Mbps / 30fps | PowerPoint 2016+ 与 WPS 均可内嵌播放，不依赖 QuickTime |
| 音频 | **不放语音**，只留轻音乐或静音 + 硬字幕 | 现场音响不可控；主讲人现场讲；字幕保证印刷版可读 |
| 播放方式 | 点击播放，不自动播放；进度条隐藏；封面帧设为该段第一关键帧 | 主讲控制节奏；切页时不会突然出声 |
| 单文件大小 | 每段 ≤ 40 MB，整 pptx ≤ 150 MB | 邮件与预检 |
| 字体 | 页面全部用 微软雅黑 / 思源黑体 并**嵌入字体**；视频内字幕烧进画面 | 预检项「字体是否正常」 |

### 3.3 录制前要在产品里准备的事

- 演示租户 `npm run seed:reset` 重灌，确保广场、看板、行业对照都有数据；
- 演示账号历史对话清空，重新按分镜走一遍；
- 三天回访：主干是真实时间，不做加速。**录制方案**：先在 D-3 天完成呼吸练习，D 日录回访段；或直接在数据库把该回访 `due_at` 改到当前时间后再录（只动 demo_seed 数据，录完复原）；
- 危机线个案编号、疗愈师工作台账号提前建好；
- 手机录屏关闭通知、调到满电、非 VPN 状态栏（状态栏可后期裁掉）；
- 每段录 2–3 遍，取最顺的一遍剪辑，转场处加 0.3s 淡入淡出。

### 3.4 静帧与打印

- 每个视频页右侧是视频，左侧放 3 个「你将看到」要点；页面底部放 3 张 240px 高的关键帧缩略图，打印版靠这个读；
- 备份页放 6 帧分镜，图下一行字；
- 所有截图统一做手机外框（同一款样机、同一阴影），HR 看板截图统一浏览器边框。
