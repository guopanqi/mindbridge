## 1. 核心理念

企业心理支持的最大痛点是——**员工要么不敢求助，要么求助后得到的只是"治标不治本"的话术**。

MindBridge AI 提出 **"AI预警与推荐 + 疗愈师深度陪伴"** 的双轨模型：

| 轨道 | 角色 | 核心任务 | 国际疗愈师赛题对齐 |
|---|---|---|---|
| **AI轨道** | 倾听者 + 匹配师 | 通过轻量级识别方式感知员工情绪状态、主动预警、个性化推荐疗愈资源 | 数字疗愈与AI辅助支持 |
| **疗愈轨道** | 转化师 + 陪伴者 | 能量疗愈、情绪疏导、深层转化与长期成长 | 疗愈师主体性与专业胜任力 |

> **AI不做诊断，只做"读数"和"吹哨"。真正的疗愈——解读报告、谈心疏导、工作调整、一对一陪伴——全部由人来完成。**

AI树洞正是"AI轨道"中承担**"倾听 + 吹哨"**职责的具体产品形态。

## 2. 产品定义：AI树洞——24小时匿名倾诉平台

> 国内市场最主流的 AI 情绪识别方式（与"1分钟心灵体检"并列两大主流方式，覆盖六大高内耗行业中的绝大多数场景）。

| 维度 | 内容 |
|---|---|
| **真实案例来源** | 郑州高新区总工会心理健康智慧化平台，接入 DeepSeek 大模型，融合自然语言处理技术，为职工提供 24 小时不间断的智能心理支持，上线后累计响应职工诉求超 **1300 次** |
| **适用行业** | 所有行业 |
| **技术门槛** | 低（小程序即可部署） |
| **员工接受度** | 高（完全匿名） |
| **国内市场成熟度** | ★★★★★（需求最旺盛，小程序/SaaS平台已非常成熟，部署周期 1-2 周，是当前企业采购心理关爱服务的**首选方式**） |

**为什么员工愿意用**：完全匿名、24小时可用、没有评判压力。员工不用面对任何人，对着手机就能说出心里话。

### 2.1 AI 做什么

1. **倾听**：让员工把话说出来——倾诉本身就是疗愈。AI 以共情式回应承接员工的情绪表达（例："听起来你最近真的很辛苦，愿意多说一点吗？"）
2. **关键词预警**：基于认知行为疗法（CBT）的基本模型，扫描倾诉内容中的情绪信号，引导员工从情绪宣泄走向认知重构。

### 2.2 关键词预警机制

| 预警等级 | 关键词示例 | AI 自动触发动作 |
|---|---|---|
| **绿色** | "好累""压力大""睡不着" | 自动推送一条疗愈资源（正念音频/呼吸练习链接） |
| **黄色** | "快撑不住了""想辞职""天天失眠" | 推送疗愈资源 + 系统提醒 HRBP 关注该团队整体状态 |
| **红色** | 极端词汇 | **立即转接专业心理咨询师** + 通知企业 EAP 专员 |

### 2.3 关键设计原则

> 采用 **"AI预警 + 人工复核"** 的闭环机制——AI 预警后必须经**人工复核**，疗愈师或 HRBP 确认后再决定是否介入，**AI 不自动定性任何员工**。

## 3. 企业应用场景中的角色

AI树洞是"通用预防型"场景的基础设施，也是六大高内耗行业场景中最常出现的 AI 轨道工具：

| 场景类型 | 具体场景描述 | AI树洞的角色 | 疗愈轨道的角色 |
|---|---|---|---|
| **通用预防型** | 全员日常情绪状态监测、心理风险预防、EAP 常态化运营 | 24小时倾诉通道 + 自动推送疗愈资源 + 情绪趋势预警 | 全员心理健康教育 + 自助疗愈工具包 + 自愿预约一对一咨询 |
| **互联网/IT** | 项目赶工期集体焦虑 + 35+ 员工"被替代"存在性恐慌 | 识别焦虑关键词 + 追踪职业身份相关倾诉内容 | 「情绪红绿灯」正念工作坊 + 「身份重塑叙事疗愈」深度小组 |
| **金融/银行** | KPI 高压下的情绪耗竭 + 高频决策疲劳 + 竞争性孤独 | 监测业绩高压相关倾诉（+ AI思想画像辅助研判压力成因） | 「积极心理与管理提升」培训 + 「跨团队疗愈小组」 |
| **医护/护理** | 长期共情疲劳 + 抢救/临终场景下的生死无意义感 | 持续倾听（+ 1分钟心灵体检快速筛查共情疲劳） | 巴林特小组 + 「天气预报+困境盲盒」团体工作坊 + 正念工间操 |
| **教育** | 教学+行政+家校沟通多重角色耗竭 + 家长投诉焦虑 | 追踪情绪耗竭指标 + 识别沟通焦虑信号 | 奥尔夫音乐疗愈 + 「痛点速写+ABC情绪理论」工作坊 + 「先育己再育人」沉浸式工作坊 |
| **客服/服务业** | 持续情绪劳动疲劳 + 客户负面情绪污染 + 机械重复感 | 识别情绪崩溃风险 + 自动推送情绪暂停提醒 | 「心流插花」艺术疗愈 + 正念冥想+芳香疗愈 + 「解压充电」趣味培训班 |

**通用预防型场景的兜底逻辑**：并非所有员工都会主动求助，也并非所有心理问题都会被识别。AI树洞作为 **24小时倾诉通道**，确保即使没有触发预警信号，员工也能获得常态化的心理支持，是员工心理关爱体系的基础设施。

## 6. AI 推荐引擎：从树洞信号到疗愈行动

### 6.1 三步转化模型

| 步骤 | 名称 | 核心任务 | 输出 |
|---|---|---|---|
| ① | **信号识别** | 树洞（等四种方式）捕捉员工情绪信号 | 情绪标签 + 预警等级 |
| ② | **方案匹配** | 根据情绪标签、员工画像、行业特征，匹配最优疗愈资源 | 个性化推荐清单 |
| ③ | **触达执行** | 通过企业 IM 自动推送 + 疗愈师人工复核 + 效果追踪 | 完整闭环 |

### 6.2 推荐决策树（简化流程）

```
AI树洞识别到的信号
   │
   ▼
第一步：判定预警等级 —— 绿色（日常）/ 黄色（需关注）/ 红色（紧急）
   │
   ▼
第二步：匹配疗愈资源（情绪标签 → 活动类型映射）
   疲惫感 → 能量唤醒工作坊 / 正念音频
   焦虑感 → 正念呼吸工作坊 / 呼吸着陆法
   低落感 → 叙事疗愈小组 / 心理嘉年华
   烦躁感 → 艺术疗愈工作坊 / 身体觉知与释放
   孤独感 → 跨团队疗愈小组 / 沙盘疗愈
   │
   ▼
第三步：差异化触达
   绿色：自动推送资源链接
   黄色：人工复核后推荐
   红色：紧急转接 + 人工介入
```

| 行业 | 常见情绪信号（树洞倾诉原文示例） | AI 识别方式 | 自动推送资源（绿色） | 进阶推荐活动（黄色/红色） |
|---|---|---|---|---|
| **互联网/IT** | "赶不上了""又要通宵""怕被裁" | AI树洞 | 三分钟呼吸着陆法音频 | 「情绪红绿灯」正念工作坊 →「身份重塑叙事疗愈」小组 |
| **金融/银行** | "业绩压垮了""睡不着""不想干了" | AI树洞 + AI思想画像 | 5分钟正念音频 | 「积极心理与管理提升」培训 →「跨团队疗愈小组」 |
| **医护/护理** | "太累了""看不到头""面对死亡" | 1分钟心灵体检 + AI树洞 | 工间舒展操引导 | 巴林特小组 →「天气预报+困境盲盒」团体工作坊 |

### 6.4 树洞专属触发规则

| 触发条件 | 系统自动动作 | 人工介入节点 |
|---|---|---|
| 树洞出现关键词"焦虑/来不及/压力大"≥1次 | 自动推送正念呼吸音频链接 | 无需人工介入 |

### 6.5 个性化推荐逻辑（三维度动态调整）

## 7. AI 识别流程闭环

```
第一步：员工主动/被动表达
   主动：在 AI树洞匿名倾诉
   被动：1分钟心灵体检 / 摄像头情绪识别

第二步：AI 关键词/情绪识别
   输出：[情绪标签] + [预警等级]
   标签：疲惫感 / 焦虑 / 低落 / 烦躁 / 平静 / 希望 等
   等级：绿色 → 黄色 → 红色

第三步：差异化触发动作
   绿色：自动推送疗愈资源
   黄色：系统提醒 HRBP 关注
   红色：立即转接专业咨询师

第四步：人工复核 + 疗愈介入
   疗愈师/HRBP 复核 → 确认后选择介入方式
   • 一对一能量疏导（红色/黄色高频）
   • 团体疗愈工作坊邀请（黄色群体）
   • 工作调整建议（思想画像辅助）

第五步：效果追踪 + 闭环反馈
   AI 追踪情绪变化 → 生成成长报告 → 优化后续推荐
```

**核心闭环原则**：

1. **AI只做识别和推荐**，不做诊断和治疗；
2. **所有预警必须人工复核**，确保不误伤、不标签化；
3. **真正的疗愈由人来完成**——疗愈师、HRBP、主管协同介入。

## 8. 全流程示例：小王的 AI树洞推荐旅程（互联网公司员工）

```
【第1天】小王在AI树洞倾诉："项目赶不上了，又要通宵，好焦虑"
  AI识别：关键词"赶不上""通宵""焦虑" → 绿色预警

【第3天】小王在AI树洞倾诉："还是没赶上，觉得自己好没用"
  AI识别：新增"没用" → 累计焦虑信号3次 → 升级黄色预警
  AI动作：① 推送「情绪红绿灯」正念工作坊报名链接
         ② 提醒HRBP关注研发部团队氛围
         ③ 生成周报："研发部本周焦虑信号上升40%"

【第5天】小王报名并参加「情绪红绿灯」工作坊
  活动后情绪温度从4.2升至6.5 → AI记录改善幅度
  小王带走《三分钟呼吸法》卡片 + 四象限工作纸

【第7天】AI随访：小王反馈"呼吸法有用，但还在想会不会被裁"
  AI识别：存在性焦虑残余信号 → 推荐进阶方案
  AI动作：推送「身份重塑叙事疗愈」深度小组介绍 + 报名入口

【第14天】小王参加第一次叙事疗愈小组
  AI记录：情绪轨迹开始改善，焦虑标签频率下降
  疗愈师反馈："小王在小组中分享了自己的职业迷茫，获得了组员支持"
```
