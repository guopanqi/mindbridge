## 三、修复明细与判断依据

### 1. SKIP-1：跳过处境选择后每次重进都被整屏弹窗挡住（已修）
- 根因：`finish(null)` 不调任何接口，`context_decided_at` 永为空，每次 `boot → enterApp` 重问。
- 判断：跳过 = 明确决定“暂不提供处境信息”，应记为已决定。服务端与「我的 → 修改 → 未选择」本就支持 `contextTag='none'`（`CONTEXT_TAGS` 含 `none`，我的页渲染“未选择”），无需改接口。
- 改动：`src/views/context-prompt.js` —— `finish(null)` 改为持久化 `api.setContext('none')`（失败不挡路）；`test/me-context.test.js` 锁定契约（none→已决定；未知标签仍 400）。

### 2. CTX-3：处境弹窗 Esc 关不掉、无焦点管理（已修）
- 改动：同文件 —— Esc 等同跳过（同样持久化）；打开时焦点进入首个选项；Tab 陷阱；关闭后焦点回到原处；`aria-labelledby` 指向标题。
- 判断：整屏模态必须给键盘用户同等出口；Esc 语义与「暂不选择」一致，不另外分叉。

### 3. TOUCH-1：页头「隐私说明」31px 高（已修）
- 改动：`public/styles.css` —— `.ghost` 加 `min-height: 44px; inline-flex 居中`。影响两处（页头按钮、「查看数据与隐私说明」宽按钮），均为正向。
- 判断：44px 取 Apple HIG 而非 WCAG 最低 24px，因为这是页头常驻操作；视觉变化仅按钮略高一圈，截图确认可接受。
