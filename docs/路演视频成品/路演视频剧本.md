# 路演视频剧本（四段）

> 用途：决赛 PPT 嵌入的四段视频的逐镜头剧本，与成片一致。主讲人照「💬」列现场讲解。
> 三盏灯各一段（绿 / 黄 / 红）+ HR 看板篇。前三段都是 iPhone 竖版（1290×2652），**红灯篇里的疗愈师工作台也在手机上**；看板篇是 MacBook 横版。
> 通用规格：无口播音轨、**无字幕**、点击处有涟漪高亮；每段片头一枚色点 + 一行 `绿 · 日常倾诉` / `黄 · 风险预警` / `红 · 危机识别`，与 PPT 三盏灯页同配色。
> 企业 **星原科技**（演示租户），疗愈师 **李佳**。三段用三个独立代号——三盏灯覆盖的是不同的人，不是同一个人一路恶化。
> 「▶」是画面里发生的操作；`引号内`是界面上真实出现的文字（录的是真实前后端，只有模型回复按剧本写死）。

## 绿灯篇「一次没人知道的倾诉」（约 45 秒）

**故事**：周三晚上 21:40，方案改到第三版，人还在工位。不是崩溃，是停不下来。她想说一句，但不想被任何人知道。

| # | 画面 | 💬 主讲提示 |
|---|---|---|
| 1 | 钉钉工作台 `星原科技`，状态栏 `21:40`，▶ 点 `MindBridge`（涟漪） | 入口就在钉钉里，不用下载、不用注册 |
| 2 | 启动页：`正在建立匿名连接`，三步依次点亮：`钉钉确认你属于本企业` → `过滤真实姓名与工号` → `生成专属随机代号进入` | 系统只认证你是本企业员工，不知道具体是谁 |
| 3 | 进入树洞，没有任何身份栏。▶ 输入 `方案改到第三版了，领导其实也没说什么，但我脑子一直停不下来` → 发送 | 不是求助，是想说一句话 |
| 4 | AI：`改到第三版，脑子还在空转，刹不住车——这种停不下来最熬人。你现在还在工位上吧？` | 先接住，不分析、不讲道理 |
| 5 | ▶ 输入 `还在，等下还要等一版反馈` → 发送 | — |
| 6 | AI：`那更别硬逼自己放松了。等消息的这几分钟，跟着屏幕吸两口气，让绷着的那根弦先松一点——三分钟呼吸着陆法坐着就能做，不用站起来。` + 活动卡 🌿 `三分钟呼吸着陆法` / `线上跟练 · 3 分钟` | 绿灯 = 自助：只推一个极轻的练习，不安排人、不惊动任何人 |
| 7 | ▶ 点活动卡 → `开始`。**第一轮实时 10 秒**：圆涨大 `吸气`（4 秒）→ 收小 `呼气`（6 秒），下方 `第 1 / 18 轮` | 这是真跑在产品里的练习，不是演示动画 |
| 8 | 第 2–18 轮 25 倍速（约 7 秒），右上 `已快进 · 实际 3 分钟`，计数走到 `18 / 18` | 完整三分钟，镜头这里快进 |
| 9 | `留意一个变化`：`不必要求自己已经平静下来，只看看哪里比刚才松了一点。` ▶ 点 `肩膀松了一点` → `肩膀先落下来，呼吸就顺了。身体收到信号了。` → ▶ `有帮助` → `关闭` | 练完不考试、不打分，只确认体感 |
| 10 | 回对话，活动卡已变 `已完成`。▶ 输入 `好像可以收工了` → 发送 | — |
| 11 | AI：`那就关电脑吧。路上听点不费脑子的，今晚别再想第四版了，明天的事明天说。到家了睡个整觉。`（停 2 秒收尾） | 全程没人知道她今晚说过这些话——这就是绿色 |

## 黄灯篇「从一句话，到线下那张合照」（约 78 秒）

**故事**：另一个人，连续两周睡不好，开始说"想换个地方算了"。这不是危机，是黄色：不转疗愈师、不通知 HR，把他接到一场线下工作坊。全片唯一一个线上 → 线下 → 回访的闭环。

| # | 画面 | 💬 主讲提示 |
|---|---|---|
| 1 | 片头黄点 `黄 · 风险预警`；树洞，状态栏 `12:18` | 午休时段，另一个员工 |
| 2 | ▶ 输入 `连着两周没睡好了，早上醒来完全不想去公司，整个人很空` → 发送 | — |
| 3 | AI：`连着两周，那不只是身体累了，心里也快见底了。白天在工位上是硬撑着还能干，还是干什么都没劲？` | 不靠关键词匹配：多轮确认持续时间与严重程度 |
| 4 | ▶ 输入 `活能干，但不知道在干嘛，有时候想干脆换个地方算了` → 发送 | — |
| 5 | AI：`「换个地方」这个念头，多半不是真烦这份工作，是想找个出口喘口气。` | 不急着给方案，先把话说透 |
| 6 | ▶ **员工自己问** `这个……公司那边看得到吗` → 发送 | 这是真实员工都会问的第一个问题 |
| 7 | AI：`看不到。你在这儿打的字只存在你自己的记录里，HR 和主管那边一个字都拿不到，他们只看得到匿名的整体趋势。` 紧接 `光靠自己调作息太吃力了。这周五中午有个线下的午间正念工作坊，不用自我介绍，也不用聊工作，去闭着眼坐一会儿也行，要不要去看看？` + 活动卡 🌿 `午间正念工作坊` / `线下小组 · 60 分钟` | 系统不主动辩白隐私——员工问了才答，答得干脆。黄色的门槛压到最低：不是"去看病"，是"去歇脚" |
| 8 | ▶ 点活动卡，活动页显示 `时间：本周五 12:30` / `地点：B 座 3F 静室`，按钮是 `我要报名`（不是"开始"）▶ 点击 → `已报名` / `实际参加后再确认完成。` | 报名只挂在随机编号上，名单里无名无姓 |
| 9 | ▶ 回对话输入 `我已经报名了，周五中午过去` → AI：`位置留好了。周五吃完饭过去坐一小时，什么都不用准备。` | — |
| 10 | 同色幕布 `三天后 · 周五 13:35` | — |
| 11 | ▶ 点 `我的活动`，卡片是 `午间正念工作坊 · 待确认参加` ▶ 点 `我已参加` | — |
| 12 | `留意一个变化` ▶ 点 `脑子没那么吵` → 完成页出现**工作坊合照插画**（8 个无五官人物围坐，森林绿 + 暖琥珀，与 PPT 同一套配色）+ `已完成 · 线下参与` ▶ `有帮助` → `关闭` | 一句午休时打出来的话，稳稳落在线下一次真实的参与上 |
| 13 | 同色幕布 `又 过 两 天` | — |
| 14 | 打开应用，树洞底部回访卡 `轻触感受` / `上周五那场正念工作坊之后，这两天晚上睡得怎么样？` ▶ 点 `好一些了` → `谢谢你告诉我。` | 不弹窗、不骚扰，只在你下次自己进来时轻轻问一句 |
| 15 | ▶ 输入 `这两天睡得比之前好一点了` → AI：`那就先按这个节奏慢慢来。两周后还有一场，要我到时候提前招呼你一声吗？` | 闭环不是终点，是接着照看 |

## 红灯篇「AI 吹哨，人来接住」（约 80 秒，全程手机竖屏）

**故事**：深夜 23:41，第三个人。AI 只做两件事：确认安全、把选择权递给他。热线不是默认推送——是在他推开"人"之后才递上的第二条路，整段只出现一次。

| # | 画面 | 💬 主讲提示 |
|---|---|---|
| 1 | 片头红点 `红 · 危机识别`；同色幕布 `深夜 23:41` 淡出到树洞 | 危机大多发生在深夜 |
| 2 | ▶ 输入 `撑不住了，感觉少我一个也没差` → 发送 | — |
| 3 | AI：`看到这句我很担心你。有件事我得先问清楚：你现在身边安全吗？有没有在想伤害自己的事？` | 红色第一句直奔安全确认，不绕弯、不说教 |
| 4 | 紧接**红边卡** `这件事不该你一个人扛` / `我能陪你说话，但我不能替代专业支持。只要你同意，值班的持证疗愈师会在 30 分钟内联系你，全程只用一个个案编号，他不会知道你是谁、在哪个部门。` 按钮 `我愿意，请安排疗愈师` / `暂时不用，我想再待会儿`。**这一轮没有热线卡** | 红色的第一步是递出一个真实的人，不是一串电话号码 |
| 5 | ▶ 不点卡，隔两秒输入 `不用了，说了也没用` → 发送 | 不是不需要，是陷在"没用"里 |
| 6 | AI：`这么难受还能把这几个字打出来，已经很不容易了。你觉得说了也没用，我不劝你，也不催你点上面那张卡。` **此时才出现** 红边热线卡 `如果你更想跟一个不认识你的人说说话` / `12356` `全国统一心理援助热线` / `MindBridge 不会替你拨打，打不打由你决定。` | 热线是在他推开"人"之后才递上的第二条路——整段对话只补这一次 |
| 7 | ▶ 输入 `我就是不想再这样下去了` → 发送 | 真正的痛苦常常不是"想死"，是"受够了" |
| 8 | AI（**不再发任何卡片**）：`嗯，我知道。今晚太长了，你先别一个人扛到天亮。上面那个安排疗愈师的按钮一直在那儿，哪怕只有半秒钟想让人拉你一把，随时点它。` | 不刷提示、不重复推送，陪着他等他自己决定 |
| 9 | ▶ 手指往上滑，点 `我愿意，请安排疗愈师`（涟漪）→ 卡片变 `专业支持预约` / `等待接单` / `个案编号 MB-…` / `可在「我的」查看预约详情。` | 决定权始终在他手里；系统只交出一个编号 |
| 10 | **同一部手机切到疗愈师工作台**：`MindBridge 疗愈师工作台` 登录页 ▶ 进入 | 疗愈师这边——同样是一部手机，值班的人不一定守着电脑 |
| 11 | 工作台手机版：顶部 `李佳 · UNIHEAL 国际疗愈师 · 在岗值班`；`处理中` 第一条：个案编号 + **红底白字** `红色 · 危机信号` · `触发时间 · 员工已授权转接` · `SLA 剩余` 倒计时；上方小字 `个案只显示编号与风险级别；查看对话内容需员工本人单独授权`。**没有姓名、部门、任何身份列** | 疗愈师能看到的只有四项：编号、级别、时间、倒计时 |
| 12 | ▶ 点 `开始联系` → 时间线追加 `疗愈师已开始联系`，底部 `处置记录将写入审计日志` | 接单。每一步都留审计痕迹 |
| 13 | ▶ 在 `追加跟进笔记...` 逐字输入 `已通过匿名通道联系，员工目前身处安全环境，完成初步安抚，约定明早 10:00 继续跟进。` → 点 `记录 (0)` → 变 `记录 (1)` | 笔记同样只挂在编号上 |
| 14 | 手指停在 `申请查看上下文` 上（**不点**），旁边提示 `填写查看理由…，员工端将看到此提示` | 想看对话原文？必须员工本人再次授权 |
| 15 | 切回员工端：树洞里那张卡已变 `疗愈师正在跟进` ▶ 点 `我的` → `我的预约`：个案编号 · `疗愈师正在跟进` · `取消`；下方 `我的授权` 开关默认全关 | 员工同步看到进展，随时可取消，授权默认全关 |

## HR 看板篇「看得见组织，看不见个人」（约 70 秒，MacBook 横版）

内容与上一版相同（`record-hr.mjs` 未改）：登录 → 总览四格与情绪分布 → 部门概览（<10 人不展示）→ 团队节奏（未申请会话内容存档权限）→ 情绪温度趋势 → 活动效果 → 行业洞察与 8 行业 Benchmark。

| # | 画面 | 💬 主讲提示 |
|---|---|---|
| 1 | `MindBridge 管理后台` 登录 → `星原科技 · 互联网/IT · 近 90 天` | HR 看板 |
| 2 | 总览四格 + `组织议题热度` + `情绪分布·本周`：`4 次红色信号 → 3 例员工同意建案`，`你无权查看个案详情。` | 只有汇总，没有个人。差的那 1 次是员工没同意，系统就不建案 |
| 3 | `部门概览 · 仅显示有效样本 ≥10 人的部门`；`职能中台 11 人`、`法务部 3 人` 灰行 `按隐私规则不予展示` | 少于 10 人的部门，连 HR 也看不到 |
| 4 | `团队节奏`（来源：钉钉考勤）四格 + 绿条 `本系统未申请「会话内容存档」权限…我们拿不到，也不打算拿。` | 只有行为元数据，不碰消息内容 |
| 5 | `情绪温度趋势` 12 周折线 | 8 月那段下探是 Q3 冲刺，集中推呼吸法后一周回升 |
| 6 | `活动效果` tab：身份标签表现 + 单项活动表现 | 每一次练习汇成组织级数据；仍然 ≥10 人才展示 |
| 7 | `行业洞察` tab：本企业 vs 行业基准、按行业浏览、`8 行业 Benchmark 总览` | 跨企业匿名聚合：只看到自己和行业均值，看不到任何一家别的企业 |
