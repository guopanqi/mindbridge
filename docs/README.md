# 工程文档

本目录只保留当前工程约定、内测操作和研究数据说明。当前组织类型、入口、正式地址以及评审聚合链接集中维护在[组织、入口与地址](组织-入口-地址.md)。修改该文档时须核对其中员工、管理和疗愈师链接仍可访问；评审聚合页依赖这三条子链接。

## 当前使用

- [组织、入口与地址](组织-入口-地址.md)：唯一的组织模型、入口和评审链接说明。
- [公开组织内测执行与测试手册](公开组织内测执行与测试手册.md)：创建组织、邀请参与者、按组织隔离测试及报告结果。
- [内测组织与研究数据字典](内测组织与研究数据字典.md)：匿名主体、事件字段、导出和分析口径。
- [小规模内部试点数据分析方案](小规模内部试点数据分析方案.md)：少量真实参与者的测试前记录、结束后计算口径与报告模板。

每个应用的启动、配置和发布步骤写在对应目录 README 中。路演材料在 [`路演/`](../路演/)，不作为产品配置或数据来源。
