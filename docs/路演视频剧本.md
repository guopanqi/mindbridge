# 路演视频剧本（三段）

> 用途：决赛 PPT 嵌入视频的逐句剧本。你审文案，我按此制作演示页并录制。
> 通用规格：无口播音轨、**无字幕**（下表「💬」列改为主讲人现场讲解提示，不烧进画面）、点击处有涟漪高亮；手机段用 iPhone 样机外框，桌面段用 MacBook 样机外框。
> 演示主角代号统一为 **晚风-QBUX**，企业 **星原科技**（演示租户），三段连成一个故事。
> 「⏱」是该镜头时长；「▶」是画面里发生的操作；「💬」是烧进画面的字幕；`引号内`是界面上真实出现的文字。

## 视频 A · 日常线「一次没人知道的倾诉」（目标 70 秒）

**故事**：客服岗员工，周三下午，被客户拖着的烦躁。想说，但不想被任何人知道。

| A11 | 4s | 回到对话。活动卡状态变为 `已完成` / `查看结果`。▶ 输入 `好多了 谢谢你` → 发送 | — |

| A13 | 6s | 树洞底部出现回访卡：`轻触感受` / `上次做完呼吸练习后，今天有没有感觉稍微松一点？` 三个按钮 `松一点了` `差不多` `更紧了` ▶ 点 `松一点了` → 卡片变 `谢谢你告诉我。` | 不打扰，不推送；下次打开时轻轻问一句 |

## 三段共用的视觉规范

- 手机段：iPhone 深色样机外框，状态栏固定 `9:41` / 满格 / 满电（A 段）、`23:41`（B 段）；无通知、无 VPN 角标。
- 桌面段：MacBook 样机外框，浏览器无书签栏，地址栏只显示 `mindbridge` 字样。
- 点击：手机为半透明圆形涟漪从点击点扩散 300ms；桌面为鼠标指针 + 点击时圆环高亮。
- 打字：手机端逐字出现（60ms/字），配输入框光标；桌面端 40ms/字。
- 转场：段内 0.3s 淡入淡出；「三天后」「两周后」用 1.5s 黑场 + 一行浅色时间字样（这是唯一出现在画面里的文字提示）。
- 每段末尾定格 3 秒，方便 PPT 里取封面帧。
