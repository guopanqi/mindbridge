# 路演视频剧本（三段）

> 用途：决赛 PPT 嵌入的三段视频（`scripts/demo-video/out/A.mp4` / `B.mp4` / `C.mp4`）的逐镜头剧本，与成片一致。主讲人照「💬」列现场讲解。
> 通用规格：无口播音轨、**无字幕**、点击处有涟漪高亮；手机段 iPhone 外框，桌面段 MacBook 外框（B 段三部分拼在同一张 2160×1440 画布上）。
> 演示主角代号 **小满-C9UE**，企业 **星原科技**（演示租户），疗愈师 **李佳**，个案编号 **MB-G9JXR6**。三段连成一个故事。
> 「⏱」是该镜头在成片中的起止秒数；「▶」是画面里发生的操作；`引号内`是界面上真实出现的文字。

## 视频 A · 日常线「一次没人知道的倾诉」（80 秒，1290×2652 竖版）

**故事**：客服岗员工，周三下午，被客户拖着的烦躁。想说，但不想被任何人知道。

| # | ⏱ | 画面 | 💬 主讲提示 |
|---|---|---|---|
| A1 | 0–3 | 钉钉工作台（`星原科技`），「常用应用」里点 `MindBridge` 图标（涟漪） | 从钉钉工作台进入，不用注册、不用登录 |
| A2 | 3–8 | 启动页：`正在建立匿名连接` / `你的姓名与工号已被脱敏过滤，不会记录到系统中。` 三步依次点亮：`钉钉确认你属于本企业` → `过滤真实姓名与工号` → `生成专属随机代号进入` | 系统只知道你是本企业员工，不知道你是谁 |
| A3 | 8–12 | 进入树洞。欢迎语：`你好，我是你的倾诉伙伴 MindBridge。这里是一处完全属于你的私密树洞……` 没有任何身份栏 | 页面上没有名字，没有头像 |
| A4 | 12–16 | ▶ iOS 键盘弹出，逐字打出 `今天和一个客户扯皮，一直说过两天过两天，烦死了` → 点 `发送`（涟漪）→ `正在听` | — |
| A5 | 16–20 | AI 回复：`跟客户来回拉锯、对方一直拖，那种憋着的火确实挺磨人的。是今天这一单特别难缠，还是最近这类事一直没断过？` | 先接住情绪，不急着给建议 |
| A6 | 20–27 | ▶ 输入 `最近一直这样，一个男的，每天都说过两天过两天` → 发送 | — |
| A7 | 27–32 | AI 回复：`天天被吊着，心里那股烦劲儿很难自己消掉。试试那个三分钟呼吸着陆法吧——它不要求你做别的，就跟着屏幕上的圆慢慢吸、慢慢呼……` 紧接着推出活动卡：🌿 `三分钟呼吸着陆法` / `跟着屏幕上的圆一起吸气和呼气，让身体先从赶进度的紧绷里退下来。` | 识别到「持续性烦躁」→ 推荐轻量自助练习 |
| A8 | 32–34 | ▶ 键盘收起，点活动卡。活动页从底部滑上：`三分钟呼吸着陆法 · 线上跟练 · 3 分钟` ▶ 点 `开始` | — |
| A9 | 34–45 | `跟着圆呼吸 1/2`：圆随 `吸气 / 呼气` 放大缩小，下方计数 `第 n / 6 轮`（真实 3 分钟，成片 6 倍速压到 11 秒） | 三分钟 · 只跟着圆呼吸。练习本身就这么简单 |
| A10 | 45–54 | `留意一个变化 2/2`：`不必要求自己已经平静下来，只看看哪里比刚才松了一点。` 四个选项 `呼吸变慢了 / 肩膀松了一点 / 脑子没那么吵 / 还是老样子` ▶ 点 `肩膀松了一点` → `体验结束 · 已记录完成`，`肩膀是最先替我们扛紧张的地方。它松开，说明身体收到了信号。` 体验反馈 ▶ 点 `有帮助` → `关闭` | 练习完只问一句「哪里松了」，不打分不考试 |
| A11 | 54–66 | 回到对话，活动卡变 `已完成` / `查看结果`。▶ 输入 `好多了 谢谢你` → 发送 → AI：`真好，能松下来一点就够了。之后再被拖着的时候，随时回来，我都在。` | — |
| A12 | 66–69 | 同色幕布 `三 天 后` | 三天后再打开 |
| A13 | 69–76 | 树洞底部出现回访卡 `轻触感受` / `上次做完呼吸练习后，今天有没有感觉稍微松一点？` 三个按钮 `好一些了 / 差不多 / 更难受了` ▶ 点 `好一些了` → 卡片变 `谢谢你告诉我。` | 不推送、不打扰；下次打开时轻轻问一句 |
| A14 | 76–80 | ▶ 点底部 `我的活动` tab。`活动记录`：`三分钟呼吸着陆法 · 已完成 · 线上自助 · 你的评价：有帮助`，按钮 `再做一次 / 查看结果` | 每一次练习都留下可度量的痕迹——但没有名字 |

## 视频 B · 危机线「AI 吹哨，人来接住」（72 秒，2160×1440 横版）

## 与录制脚本的对应

- A：`scripts/demo-video/record-a.mjs`，合成 `assemble.mjs A phone-941 --speed 33.5:102.5:6`
- B：`record-b.mjs`（B1 手机 / B2 桌面 / B3 手机），各段 `--canvas 2160x1440` 后 `concat.mjs B B1 B2 B3`
- C：`record-c.mjs`，合成 `assemble.mjs C laptop`
- 改动画面文案后：文案在员工端/后台源码或 `model-stub.mjs`；改完重录对应段即可（详见 `scripts/demo-video/README.md`）。
